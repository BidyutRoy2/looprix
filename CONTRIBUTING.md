# Contributing

Thanks for helping Looprix. Developed by Bidyut Roy — https://github.com/BidyutRoy2

1. Fork, create a branch, keep changes small and focused.
2. Never commit a stream key, OAuth token, `.env`, or `node_modules/`.
3. Run `npm test` and `npm run build` before opening a PR.
4. Security issues: report privately, never in a public issue (see SECURITY.md).
